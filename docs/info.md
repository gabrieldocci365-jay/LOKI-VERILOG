## How it works

This project implements a 4-bit digital logic module written in Verilog.

## How to test

1. Apply a clock signal to and assert low briefly to reset the design, then pull it higH for normal operation.
2. Set the desired 4-bit input values on the input pins.
3. Observe the resulting 4-bit binary output on and verify that it matches the expected truth table / state transitions.

## External hardware

No external hardware is strictly required; the design can be verified using standard switches/buttons for inputs and LEDs or a logic analyzer on the output pins.
